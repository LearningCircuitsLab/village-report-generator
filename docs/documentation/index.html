village-report-generator#

Every day, on the cluster, this repository makes an HTML report of each active project of the Training Village and publishes it on the reports website, with a calendar to choose the day.

A report has an Overview tab (corridor plot of the last days, TV report, trials per training stage, trials and performance of the last days, box occupancy, performance of the cohort), one tab per subject (training history and the session of the day) and a Problems tab listing anything that could not be drawn. A separate report shows the temperature and humidity of the room.

The analysis and figures come from lecilab-behavior-analysis; this repository only decides what goes in each report, renders it with Quarto and publishes it.

See an example report, made from the sample data by the current code.
